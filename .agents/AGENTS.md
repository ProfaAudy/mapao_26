# Regras do Projeto / Project Rules

## Fluxo de Execução de Tarefas
- Sempre que o usuário solicitar qualquer tarefa, você deve primeiro explicar detalhadamente as etapas do que planeja fazer e então pedir explicitamente a confirmação dele antes de prosseguir com as alterações nos arquivos ou execução de ferramentas.
- Sempre que houver alterações no código, mostre o resumo das modificações e peça aprovação explícita do usuário antes de realizar o commit e o push para o repositório no GitHub.
